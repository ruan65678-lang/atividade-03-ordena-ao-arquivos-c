## Sobre a atividade

Programa em linguagem C para praticar a leitura e a gravacao de arquivos e os algoritmos de ordenacao.

O programa permite:
- Criar o arquivo `dados.txt` com valores numericos.
- Ler e mostrar os valores do arquivo.
- Escolher um metodo de ordenacao.
- Salvar o resultado em `ordenado.txt`.
- Alterar um valor e ordenar novamente.

## Metodos disponiveis

- Bubble Sort
- Insertion Sort
- Selection Sort
- Merge Sort
- Quick Sort

## Como executar

1. Compile o arquivo:

```bash
gcc main.c -o atividade
```

2. Execute:

No Windows:
```bash
atividade.exe
```

No Linux ou macOS:
```bash
./atividade
```

3. No menu, escolha primeiro a opcao **1** para criar `dados.txt`.

Os arquivos de dados sao criados na mesma pasta em que o programa e executado.
